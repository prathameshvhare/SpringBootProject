> A data-driven career guidance platform that turns skills, interests, and assessment performance into practical career direction.

Smart Career Recommendation System is a web application that helps students discover suitable career paths by combining profile information, technical skills, domain interests, and assessment results. It provides personalized career matches, skill-gap guidance, and learning roadmaps in one place.

## 🧩 Problem Statement

Students often have difficulty connecting their education, current skills, interests, and assessment performance to realistic career options. Generic career advice does not show which roles are a good fit, which skills are missing, or what the student should learn next. Administrators also need a central way to maintain career data, assessment questions, and student progress.

## 💡 Solution

The system guides a student through a practical career-discovery workflow:

1. Create an account and complete a profile.
2. Select an educational background, target direction, skills, and domain interests through the onboarding wizard.
3. Complete timed assessments or discovery tests when additional skill information is needed.
4. Receive ranked career recommendations with match percentages.
5. Review assessment history, skill gaps, recommended learning actions, and career-focused project roadmaps.

Administrators can manage students, careers, skills, interests, assessments, and question banks. The admin dashboard also provides user details, recommendation summaries, and analytics.

- ✉️ Welcome email support through SMTP

## 🧠 Recommendation Approach

Recommendations are generated by comparing a user's profile with the skills and interests associated with each career. The match score combines:

- Skill alignment: up to 50 points, with primary skills weighted more heavily than secondary skills
- Domain-interest alignment: up to 15 points
- Latest assessment performance: up to 35 points

The resulting score is capped at 100 and used to rank the user's career matches. Users without profile or assessment data receive baseline career suggestions to help them begin exploring.

## ⚙️ Configuration

Before starting the application, create the MySQL database used by the application:

```sql
CREATE DATABASE careerrecommendationsystem;
```

Configure the datasource, JWT settings, and SMTP settings in the active Spring profile. Do not commit real database passwords, JWT secrets, or mail credentials. Prefer environment variables or a local, ignored configuration file for development.

The default application server runs on port `8080`, and the frontend API helper expects the backend at:

`http://localhost:8080/api`

## 🚀 Running Locally

From the backend directory, start the Spring Boot application with the Maven Wrapper.

Windows:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

Linux or macOS:

```bash
cd backend
./mvnw spring-boot:run
```

The application is available at `http://localhost:8080`.

To build and run the test suite:

```powershell
cd backend
.\mvnw.cmd clean test
```

On Linux or macOS, replace `./mvnw.cmd` with `./mvnw`.

## 🐳 Running with Docker Compose

From the project root:

```bash
docker compose up --build
```

The application is available at `http://localhost:8080`. The Docker profile expects MySQL to be reachable through `host.docker.internal`; update the Docker datasource configuration for your environment before starting the container.

Stop the services with:

```bash
docker compose down
```

## 🔌 API Overview

The backend exposes REST endpoints under `/api`. The main API areas include:

- `/api/users` for registration, login, profiles, and user administration
- Assessment endpoints for available tests, questions, submissions, and results
- Career, skill, and interest endpoints for profile and catalog data
- Recommendation endpoints for generating and viewing career matches
- `/api/admin` endpoints for administrative management and analytics

The frontend uses JSON requests and browser credentials when calling the API.

## 🌱 Sample Seed Data

The included seed data provides sample users, career paths, technical skills, domain interests, assessments, and assessment questions for development. Change or remove sample credentials before using the application in a shared or production environment.

## 🛡️ Security Notes

- Use strong, environment-specific database credentials.
- Replace the development JWT secret before deployment.
- Configure CORS with trusted frontend origins instead of a wildcard in production.
- Never use plain-text sample passwords or SMTP credentials in a production database.
- Serve the application over HTTPS when handling user accounts and assessment data.

## 📌 Project Status

This project is an actively developed academic and portfolio-style career guidance platform. The recommendation engine is rule-based and data-driven; it is not a machine-learning model despite the product's analytics-oriented interface.
